# story-videos
Daily interactive "pick the outcome" story videos for TikTok (9:16, 60-75 s, English), generated by code:
vector scenes (HTML/SVG) filmed with Playwright, local TTS (Kokoro), synthesized music/SFX, ffmpeg.

- `engine/` reusable pipeline + helpers (characters, gem, rain, captions, HUD frame)
- `stories/NNN-slug/` one folder per episode: `script.py`, `scenes.js`, `story.js`, `audio.py`, `description.txt`
- `state.json` series memory (what happened, choices, cast)
- `CLAUDE.md` the nightly playbook (what the scheduled agent does at midnight)

Run an episode: `./run.sh stories/001-blue-star` (≈ 6 min). Quick visual check only: `./run.sh stories/001-blue-star qc`.
Output: `out/<slug>/<slug>.mp4` (not committed).
